# Brand refresh, 2026-10-05

**Decision:** direction A (radii 4/8, mono eyebrows, regular-weight display) with the colours of direction C (cobalt actions on cool ink neutrals), and lime back as the accent. Valeria chose it on 2026-10-05 after two rounds of explorations in Storybook (`Foundations/Brand refresh`). A Ramp-like "volt" variant (lime as the CTA fill, warm greige) was shown and not taken: cobalt stays for actions and selection. Typeface: **Host Grotesk** (text) + **Geist Mono** (labels), chosen from four free candidates close to Ramp's commercial TWK Lausanne (Geist, Hanken Grotesk, Host Grotesk, Albert Sans); nobody in the client's market uses it. Structure: V1 of `Foundations/Brand structure` (neutral grey, mono bracket labels, accent-coloured second phrase), and the isometric lattice with power-line wires as the brand's background grid (`Foundations/Iso grid`, `Patterns/Flow diagram`). Valeria: direction approved, final result still to be tuned.

## Why the old brand read as 2020

The old brand combined several traits that are each fine on their own: saturated SaaS indigo on every fill, a lime marker behind a headline word, Outfit 700 headlines over Manrope 300 body, 16/24 px radii, soft drop shadows, icons in tinted circles and pale grey-blue tints. Together they form the recognisable startup landing page of that period.

## What current references do

About forty web sections on Mobbin were reviewed (energy, climate, EV, fintech). The patterns recur across them:

- **Radii.** Controls 2–6 px and cards 4–10 px; pills appear as a deliberate style, not as the default.
- **Display type.** Regular or medium weight at large size with tight tracking; body text at 400.
- **Emphasis.** The second phrase is set in a quieter colour instead of a marker highlight.
- **Labels.** A mono uppercase eyebrow instead of a decorative badge.
- **Surfaces.** Warm or cool paper, one strong colour, hairlines instead of shadows.
- **Icons.** Bare icons, without tinted containers.

## What changed in the system

| Layer | Before | After |
|---|---|---|
| `color/primary` ramp | indigo, 600 = #5565ea | cobalt, 600 = #2b3cf0, 700 = #1e2bc4 |
| neutrals | `color/slate/*` | new `color/ink/*` (cool, low chroma), 950 = #0a0b14; all semantic aliases moved from slate to ink |
| `background/accent` (dark card) | primary/800 | ink/950 |
| highlight family | lime (secondary/300), text secondary/900 | lime (secondary/300), text ink/950 (17.1:1); `text/highlight` lime on dark |
| `background/accent-subtle` | primary/50 | ink/100 (no blue tints) |
| role radii | container 24, control 16, inner 16, small 4 | container 8, control 4, inner 4, small 2 |
| text styles | Outfit + Manrope, weight in the name (`Bold`, `Light`, `Semi-bold`) | Host Grotesk + Geist Mono; names say the role (`Default`, `Strong`); new `Desktop/Body/Eyebrow` (Geist Mono 12/16, +8 %, uppercase) |
| Focus State | ring #687eff | ring bound to `color/primary/500` → #4d58f5 (5.21:1 on white, 3.76:1 on ink/950) |
| overlay | #02061780 | #0a0b1480 |

**Contrast** (all checked): action label 6.98:1 and 9.55:1 on hover; ghost and accent text 6.98:1; tertiary text 4.92:1 on subtle and 4.54:1 on muted; control border 5.36:1; on-accent text 12.4:1. Focus ring 5.21:1 on white and 3.76:1 on ink/950. `text/highlight-strong` (lime 700) is 4.71:1 on white but 4.32:1 on ink/50: use it on white only. Lime on light surfaces is decorative only (1.2:1). Disabled pairs are exempt.

**Naming rule** (new, for agents): text style names describe the role, never the weight. A style named "Bold" that renders at 500 is a false instruction to anyone reading the token.

## Not changed (follow-ups)

- ~~`color/slate/*` stays in Base / Color~~ Deleted in the cleanup after every direct binding was moved to ink.
- `Box Shadow/*` styles keep their values. Cards use hairlines through `tone="surface"`; shadow-md stays only for the Article pattern.
- Composition (eyebrow, quieter second line, bare icons) is a template and pattern decision. It is shown in `Foundations/Brand refresh` and in the Card feature story, and it goes into the templates wave.
- The client reference page (REG FLOW) is not restyled.

## How it was applied

`rebrand/2026-10-05-spec.json` is the single source. `rebrand/predict.mjs` applies it to the token export, so the code could be built before the Figma bridge was back. `rebrand/apply.figma.js` (steps: snapshot, variables, styles) and `rebrand/loose-fonts.figma.js` (per page, phases masters → overrides) apply the same spec in Figma. After the Figma apply, a fresh export must fingerprint-match the predicted JSON.

## Applied in Figma (2026-10-05)

- Version saved: «Before brand refresh 2026-10-05».
- Variables: 11 primary values set, 11 `color/ink/*` created (scopes copied from slate), 31 semantic aliases, 1 raw, 4 role radii. Fresh export fingerprint 227 / 3451934170, equal to the predicted JSON.
- Radii: most layers were bound to the BASE scale (radius/2xl, 3xl, sm), so changing the roles alone reached only 11 layers. `rebrand/rebind-radii.figma.js` rebound them to roles: Components 148, Sections 245, Calculator Final 85, Foundations 6. Rule: fully round today → pill; ≤ 4 px → small; control height (≤ 56 px) → control; content surface (≥ 160 × 96) or ≥ 12 px → container; else inner. Fractional radii (vector art) and the REG FLOW reference page are untouched.
- Then: text styles to Host Grotesk / Geist Mono (with the role-based names), ~800 loose text segments, logo wordmark, Feature card icon tile, the two iso size variables. Fresh export fingerprint-matched the predicted JSON (vars 229, text styles 24, effects 8).
- Cleanup (version «Before cleanup 2026-10-05 (b)»): old lime highlighter plates removed or hidden, three orphan Button instances and the Navbar orphan swapped to current components, every slate binding moved to ink (gradient stops included), the 11 `color/slate/*` variables deleted, destructive Button variants re-laid out. Lint: 0 violations.
- Legacy seen while checking: destructive Button masters overlap and use black labels (the known old masters).

## Background grid and flow diagram (2026-10-05)

- **Iso grid.** A 30° lattice (cell 56 × 32 = role sizes `size/iso-cell-w` / `size/iso-cell-h`, aliases of spacing/14 and spacing/8) with a dot at every crossing, faded from a focus point. It matches the angle of the isometric illustrations and stands for the energy grid. Use it in marketing heroes, flow diagrams and empty states; never behind product UI or body text.
- **Wires.** Wires follow the lattice (horizontal stubs, vertical runs, 30° diagonals) as thin cobalt lines; a lime pulse travels along them. With reduced motion the pulse is removed and the line stays.
- **Flow diagram pattern.** It is built from data (1–5 sources, hub steps, 1–5 targets), so an agent can generate one from a list. Sources and targets are lists and the steps are an ordered list, so the wires carry no meaning. Below 760 px of container width it stacks and drops the wires.
- **Illustrations.** Valeria's isometric renders fit the lattice. Use one tile per hero, not the whole scene. Export each tile from 3D with a transparent background, with the blues graded toward cobalt and without client signage.
