# Table

Rows of records with the same fields, to compare or scan. Built from data: give it columns and rows.

<Source language="tsx" code={`import { Table } from 'agentproof-ds/Table'`} dark={false} />

## Best practices

| | Guidance |
|---|---|
| ✅ Do | Give every table a caption, even a hidden one. It names the table and its scroll frame. |
| ✅ Do | Mark the column that names the row with `isRowHeader`. |
| ✅ Do | Align numbers, amounts and dates to the end. They get tabular figures. |
| ✅ Do | Show status with a Badge (word + icon), not a coloured dot. |
| ❌ Don't | Make whole rows clickable. Put a link or a small Button in a cell, with a name that says which row. |
| ❌ Don't | Use a table for layout or for fewer than three rows on a phone. Use a list of Cards. |

- A real `<table>`: column headers (`scope="col"`) and a row header (`scope="row"`), so cells are read with their headers.
- Sortable headers are buttons; the sorted column has `aria-sort`, and a polite status says "Sorted by Bonus, descending".
- On narrow screens the table scrolls inside a frame. Only while it overflows, the frame is a focusable region (`tabindex="0"`) named "{caption} (scrolls sideways)", so keyboard users can scroll it (2.1.1). When the table fits, there is no extra landmark, so a section with the same heading doesn't clash (`landmark-unique`). Override the name with `frameLabel`.
