# Button

Triggers an action. Use it to submit a form, confirm a step or start a task. If it only takes the user to another page, it is a link, not a button.

<Source language="tsx" code={`import { Button } from 'agentproof-ds/Button'`} dark={false} />

<Canvas of={Stories.Primary} />

## Anatomy

| Element | Description |
|---|---|
| **Label** | Required. The visible text and the accessible name. A verb that names the action. |
| **Icon** | Optional, leading. Reinforces the label (trash on Delete). Takes the label's colour. |
| **Spinner** | Replaces the icon while `isLoading`. |

## Best practices

| | Guidance |
|---|---|
| ✅ Do | Use one `primary` per view. Everything else is `ghost` or `link`. (B-R1) |
| ✅ Do | Write labels that say what happens: "Save changes", "Delete account". Not "OK". (B-R2) |
| ✅ Do | Use `tone="destructive"` for irreversible actions: filled on the final confirmation step, `ghost` when deleting is one of several actions. (B-R4) |
| ✅ Do | Keep a submit button focusable when the form isn't ready: `isDisabled` uses `aria-disabled`, and the form says what is missing. (B-R6) |
| ✅ Do | Use `onDark` on `background/inverse`, `background/accent` and `background/accent-strong` only. (B-R8) |
| ❌ Don't | Use `size="sm"` outside dense rows (tables, lists, cards). (B-R5) |
| ❌ Don't | Make a destructive button icon-only. (B-R9) |
| ❌ Don't | Use a button for navigation. Use a link. |

### Mapping to Figma

| Figma (`Button` set) | Code |
|---|---|
| `Type=Primary\|Ghost\|Link` | `variant="primary\|ghost\|link"` |
| `Tone=Default\|Destructive` | `tone` |
| `Size=L\|S` | `size="lg\|sm"` |
| `State=White` | `onDark` (appearance, not a state) |
| `State=Hover\|Focus` | CSS `:hover`, `:focus-visible` |
| `State=Disabled` | `isDisabled` (`aria-disabled`) |
| `Leading icon` + `Icon` | `icon` |
| `Border radius` | removed: decided by `variant` |
| — | `isLoading` (not in Figma yet) |

- Keyboard: Tab focuses, Enter and Space activate. A disabled button stays in the tab order and is announced as unavailable.
- Focus keeps the ghost outline and its transparent fill. The Figma `Ghost / Focus` variant fills with `background/accent-muted`, where the label drops to 3.8:1; the code does not copy that (spec B6).
