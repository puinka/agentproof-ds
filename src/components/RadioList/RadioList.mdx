# Radio list

One choice from two to six options, all visible at once. `layout="tiles"` turns each option into a card for choices that need a description or a value to compare.

<Source language="tsx" code={`import { RadioList } from 'agentproof-ds/RadioList'`} dark={false} />

<Canvas of={Stories.Tiles} />

## Best practices

| | Guidance |
|---|---|
| ✅ Do | Write the legend as the question: "How do you want to be paid?" |
| ✅ Do | Preselect the option most people choose, unless the choice has a cost or a legal effect. |
| ✅ Do | Use tiles when options carry a price, a date or a trade-off. Keep the value in `meta`, right-aligned. |
| ❌ Don't | Use it for more than six options (use a select) or for yes/no (use a Checkbox or Switch). |
| ❌ Don't | Change the page as soon as an option is chosen. The choice is applied with the form. |

- Native radios in a `fieldset` with `role="radiogroup"`; the legend names it. Tab enters the group, arrow keys change the choice.
- The selected state is shown by the dot and by a 2 px border, not only by colour.
- An error sets `aria-invalid` on the group and is read with it (`aria-describedby`).
