# About this project

**Agentproof DS is a personal, unpaid project.** Nobody commissioned it, briefed it or paid for it.

## Where the system comes from

I first built this design system for myself, to work faster and more consistently on a client's product. Nobody asked me to do it. In the end, the client's team and their developer worked with it too.

## What is mine and what is not

**The brand is not mine.** Another designer created the original branding. For this case I updated it to my own taste and to what I believe works better: sharper shapes, a new typeface, a calmer palette with one accent. The shift is deliberate but not radical, so the brand still owes a lot to the original.

**To keep the client anonymous** I changed the name and the logo. «Voltwise» is a fictional brand. I also rewrote the copy. The niche (EV drivers, energy, GHG quotas) and the rough content stay close to the real product, because the system was designed around it.

**This is not the client's product.** It does not represent the client, and the client has not reviewed or endorsed this version. The code is a reference implementation: how the system could look in an ideal setup, not production code.
